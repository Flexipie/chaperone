Take (or renew, or take over) the lease on an item. Needs an agent and a session

Usage: seamlane work claim [OPTIONS] <ID>

Arguments:
  <ID>  

Options:
      --db <DB>                  Path to the ledger (defaults to seamlane/ledger.db in the user data dir)
      --worktree <WORKTREE>      
      --branch <BRANCH>          
      --format <FORMAT>          Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
      --base-sha <BASE_SHA>      
      --lease-secs <LEASE_SECS>  Lease length in seconds, 30..=86400 (default 900)
      --takeover                 Take an item another pair holds LIVE; recorded with their name
      --dry-run                  Run the real write and roll it back; meta.dry_run is true
      --agent <AGENT>            Your agent name, [a-z0-9._-]{1,40} (default: $DAISY_AGENT)
      --session <SESSION>        Your session id, [A-Za-z0-9._:-]{1,120} (default: $DAISY_SESSION)
  -h, --help                     Print help
