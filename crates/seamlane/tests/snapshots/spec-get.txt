A spec with its slices and decisions parsed from the body. With --key, that slice alone: its section, its decisions and the spec-wide ones, and its siblings with their work item status and PR. --key without a spec finds the spec that has the slice

Usage: seamlane spec get [OPTIONS] [SPEC]

Arguments:
  [SPEC]  The spec id or its parent key (any case)

Options:
      --db <DB>            Path to the ledger (defaults to seamlane/ledger.db in the user data dir)
      --version <VERSION>  An older version (default: the newest)
      --format <FORMAT>    Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
      --key <KEY>          A slice's issue key: CORE-1235, PER-12 or owner/repo#12
  -h, --help               Print help
