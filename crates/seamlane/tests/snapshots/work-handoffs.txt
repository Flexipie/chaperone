Every handoff on an item, oldest first

Usage: seamlane work handoffs [OPTIONS] <ID>

Arguments:
  <ID>  

Options:
      --db <DB>          Path to the ledger (defaults to seamlane/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
