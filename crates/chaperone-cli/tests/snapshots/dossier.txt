The agent-only record of an issue key: notes, and one capped read of what the ledger knows about the key. Data for agents, never a gate

Usage: chaperone dossier [OPTIONS] <COMMAND>

Commands:
  note  Leave a note on a key: what you learned that the issue does not say. The same note again from the same session replays. Notes are never edited; --supersedes hides an older one from `dossier get`
  get   The key's slice and spec decisions, lanes, handoffs, files and notes, capped (48,000 bytes at most as printed); every cut is counted in its section's `omitted`. not_found when the ledger has none of them
  help  Print this message or the help of the given subcommand(s)

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
