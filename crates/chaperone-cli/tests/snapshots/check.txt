Check results a fresh session records for a lane: plan check, quality gate, merge verdict, smoke, kept tests and review rounds; and the checks the binary runs itself

Usage: chaperone check [OPTIONS] <COMMAND>

Commands:
  record  Record one check result on a work item. Refused from any session that has held it: pass your own --session. The same result again replays and writes nothing
  run     Run one check on the lane's commit in its worktree and record the result as the harness's. One run per lane at a time: a second is a conflict (exit 4). A run that fails records nothing; the same tree again replays
  help    Print this message or the help of the given subcommand(s)

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
