Check results a fresh session records for a lane: plan check, quality gate, merge verdict, smoke, kept tests and review rounds; and the checks the binary runs itself

Usage: chaperone check [OPTIONS] <COMMAND>

Commands:
  record  Record one check result on a work item. Refused from any session that has held it, except a smoke claim on a v20 lane: pass your own --session. The same result again replays and writes nothing
  run     Run one check on the lane's commit in its worktree and record the result as the harness's. One run per lane at a time: a second is a conflict (exit 4). A run that fails records nothing; the same tree again replays
  waive   Waive a check the harness runs for a lane that cannot pass it now: the plan check of a lane that coded before its plan was attacked. The owner's: refused from any session that has held the lane
  prune   Remove the build directories and checkouts beside the ledger of lanes that are done, cancelled or not in the ledger, as every `check run` and `verify` does first; a lane whose run is in progress is skipped. Writes nothing to the ledger
  help    Print this message or the help of the given subcommand(s)

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
