Run `check run` diff, tests, review and verdict on the lane's commit in that order, under one hold of the lane's run lock (a second run is a conflict, exit 4), stopping at the first step refused or not passed; the verdict runs only after a complete review that leaves no finding blocking. Prints each step and where and why it stopped. Plan and smoke are not steps

Usage: chaperone verify [OPTIONS] --work <WORK>

Options:
      --db <DB>            Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --work <WORK>        
      --agent <AGENT>      Your agent name, [a-z0-9._-]{1,40} (default: $DAISY_AGENT)
      --format <FORMAT>    Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
      --session <SESSION>  Your session id, [A-Za-z0-9._:-]{1,120} (default: $DAISY_SESSION)
  -h, --help               Print help
