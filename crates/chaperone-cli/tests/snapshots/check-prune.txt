Remove the build directories and checkouts beside the ledger of lanes that are done, cancelled or not in the ledger, as every `check run` and `verify` does first; a lane whose run is in progress is skipped. Writes nothing to the ledger

Usage: chaperone check prune [OPTIONS]

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
