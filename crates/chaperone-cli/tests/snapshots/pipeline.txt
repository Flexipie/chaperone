The pipeline documents this binary runs

Usage: chaperone pipeline [OPTIONS] <COMMAND>

Commands:
  current  The pipeline a new claim stamps: {id, hash}. Skills read the version from here rather than naming one
  help     Print this message or the help of the given subcommand(s)

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
