The pipeline documents this binary runs

Usage: chaperone pipeline [OPTIONS] <COMMAND>

Commands:
  current  The pipeline a new claim stamps: {id, hash, newer}, `newer` the embedded pipelines a first claim may stamp instead (`work claim --pipeline`). Skills read the version from here rather than naming one
  limits   The `[limits]` table of the lane's pipeline, else of the one a new claim stamps: {pipeline: {id, hash}, limits}
  history  Each version of the pipeline changelog (`## vN <time>` in <dotfiles>/claude/pipeline-changelog.md), newest first, with its entry, engine ids and `stats`' cohort numbers over its lanes: the first `pipeline vN` a handoff summary names, else the version active at the lane's first claim
  help     Print this message or the help of the given subcommand(s)

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
