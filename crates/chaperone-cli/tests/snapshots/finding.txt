A lane's review and plan check findings: list them, the lane disputes or accepts one, the owner waives one

Usage: chaperone finding [OPTIONS] <COMMAND>

Commands:
  list     Every finding of the lane's complete harness reviews, of any commit, and of its newest plan check, oldest first, with the reason of each one's newest move; blocks is true for those the no_blocking_findings gate counts
  dispute  Say an open or verified finding is wrong. Only from a session that has held the lane; it still blocks until a session that never has rules on it
  waive    Stop an open, verified or disputed finding blocking. The owner's: refused from any session that has held the lane
  accept   Say the lane will act on an open plan check finding, and how. Only from a session that has held the lane; the review is shown it
  answer   Answer an open question finding, as anyone may
  help     Print this message or the help of the given subcommand(s)

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
