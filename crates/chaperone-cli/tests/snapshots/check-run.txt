Run one check on the lane's commit in its worktree and record the result as the harness's. One run per lane at a time: a second is a conflict (exit 4). A run that fails records nothing; the same tree again replays

Usage: chaperone check run [OPTIONS] --work <WORK> <KIND>

Arguments:
  <KIND>
          Possible values:
          - diff:    Files and lines the commit changes against the merge base
          - tests:   The base branch profile's `[tests]` commands, in a fresh checkout of the commit the harness makes and removes each run; the checkout must stay at the commit and clean
          - review:  The review lenses on the commit's diff (one with a minimum the diff is under is skipped), in that checkout, each on the CLI its pipeline runner names, then a verifier that tries to refute each finding; the lane's pipeline names them (none before v20)
          - verdict: One fresh session on whether the commit should merge, from the change, the lane's goal and the harness's own diff, tests and complete review of it; a verdict stands for its tree, so the same tree and results replay it, yes or no (none before v20)
          - plan:    One fresh session attacking the plan in --file, before any code: a commit that changes a code file is refused (the owner can waive the check); the same plan on the same tree replays (none before v20)
          - smoke:   The base branch profile's `[smoke]` commands, run as `tests` runs its; no `[smoke]` table is refused, never a pass (none before v20)

Options:
      --db <DB>
          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)

      --work <WORK>
          

      --file <FILE>
          The plan file, for plan only: regular UTF-8 text of at most 64 KiB

      --format <FORMAT>
          Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key
          
          [default: json]
          [possible values: json, jsonl]

      --agent <AGENT>
          Your agent name, [a-z0-9._-]{1,40} (default: $DAISY_AGENT)

      --session <SESSION>
          Your session id, [A-Za-z0-9._:-]{1,120} (default: $DAISY_SESSION)

  -h, --help
          Print help (see a summary with '-h')
