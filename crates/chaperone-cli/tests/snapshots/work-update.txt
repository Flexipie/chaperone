Change status or fields. --expected-updated-at is the item's current updated_at; a stale one is refused as a conflict (exit 4)

Usage: chaperone work update [OPTIONS] --expected-updated-at <EXPECTED_UPDATED_AT> <ID>

Arguments:
  <ID>  

Options:
      --db <DB>
          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --status <STATUS>
          queued | claimed | active | blocked | review | done | cancelled
      --format <FORMAT>
          Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
      --reason <REASON>
          
      --blocker <BLOCKER>
          Required (or --reason) when moving to blocked
      --next-action <NEXT_ACTION>
          
      --pr <PR>
          owner/repo#N
      --branch <BRANCH>
          
      --base-sha <BASE_SHA>
          
      --spec <SPEC>
          The spec this item is a slice of (its id or parent key)
      --lane <LANE>
          
      --lane-pos <LANE_POS>
          
      --expected-updated-at <EXPECTED_UPDATED_AT>
          
      --dry-run
          Run the real write and roll it back; meta.dry_run is true
      --agent <AGENT>
          Your agent name, [a-z0-9._-]{1,40} (default: $DAISY_AGENT)
      --session <SESSION>
          Your session id, [A-Za-z0-9._:-]{1,120} (default: $DAISY_SESSION)
  -h, --help
          Print help
