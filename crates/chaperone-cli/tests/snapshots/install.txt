Write the Claude Code plugin embedded in this binary as a marketplace in the user data dir, replacing what was there, and register it with `claude plugin marketplace add` and `claude plugin install chaperone@chaperone --scope user`. Safe to run again. Never reads the ledger

Usage: chaperone install [OPTIONS]

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
