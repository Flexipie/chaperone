Run the newest pipeline's review lenses and verifier on each entry of a set of past changes, in a fresh checkout of its head, and print per entry and run hit, miss, false_alarm, clean, convention (a clean entry with only design_tests findings, not scored), skipped (not on this machine) or error (a session did not run), each entry's k of N runs, totals, the score and its mean per run. Never opens the ledger

Usage: chaperone review eval [OPTIONS] --repos <REPOS>

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --set <SET>        The set: TOML `[[entry]]` tables of name, repo, base, head, goal and, for a change with a bug the review must find, `bug = {paths, words, what}`; `known`, a list of the same, matches real leftovers that are not scored [default: evals/review.toml]
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
      --repos <REPOS>    The directory of the local clones: repo `owner/name` is read from <repos>/<name>
      --only <ONLY>      Only the entry with this name
      --runs <RUNS>      Review each entry this many times [default: 1]
  -h, --help             Print help
