Run the newest pipeline's review lenses and verifier on each entry of a set of past changes, in a fresh checkout of its head, and print per entry hit, miss, false_alarm, clean, skipped (not on this machine) or error (a session did not run), totals and the score. Never opens the ledger

Usage: chaperone review eval [OPTIONS] --repos <REPOS>

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --set <SET>        The set: TOML `[[entry]]` tables of name, repo, base, head, goal and, for a change with a bug the review must find, `bug = {paths, words, what}` [default: evals/review.toml]
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
      --repos <REPOS>    The directory of the local clones: repo `owner/name` is read from <repos>/<name>
      --only <ONLY>      Only the entry with this name
  -h, --help             Print help
