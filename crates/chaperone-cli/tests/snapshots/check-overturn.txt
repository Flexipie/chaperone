Overturn a plan waiver or a size reason: the plan gate fails again, v20's size gate applies again, and the lane may not write that waiver again. The owner's: refused from any session that has held the lane

Usage: chaperone check overturn [OPTIONS] --work <WORK> --reason <REASON> <KIND>

Arguments:
  <KIND>
          Possible values:
          - plan: The plan check's waiver
          - size: The size waiver or reason

Options:
      --db <DB>
          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)

      --work <WORK>
          

      --format <FORMAT>
          Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key
          
          [default: json]
          [possible values: json, jsonl]

      --reason <REASON>
          Why; one line, kept on the event and redacted at write

      --agent <AGENT>
          Your agent name, [a-z0-9._-]{1,40} (default: $DAISY_AGENT)

      --session <SESSION>
          Your session id, [A-Za-z0-9._:-]{1,120} (default: $DAISY_SESSION)

  -h, --help
          Print help (see a summary with '-h')
