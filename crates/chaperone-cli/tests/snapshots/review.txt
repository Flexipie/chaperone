The harness review itself, outside any lane

Usage: chaperone review [OPTIONS] <COMMAND>

Commands:
  eval  Run the newest pipeline's review lenses and verifier on each entry of a set of past changes, in a fresh checkout of its head, and print per entry and run hit, miss, false_alarm, clean, convention (a clean entry with only design_tests findings, not scored), skipped (not on this machine) or error (a session did not run), each entry's k of N runs, totals, the score and its mean per run. Never opens the ledger
  help  Print this message or the help of the given subcommand(s)

Options:
      --db <DB>          Path to the ledger (defaults to chaperone/ledger.db in the user data dir)
      --format <FORMAT>  Output format: json is one {ok, data, meta} object; jsonl is one item per line followed by a trailer that is the only line with an `ok` key [default: json] [possible values: json, jsonl]
  -h, --help             Print help
